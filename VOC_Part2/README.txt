Package contents
----------------
main.tex
    Main LaTeX report with explanation, interpretation, and embedded figures.

figures/
    Collection of cleaned summary plots and extracted/rolling plot panels used by the report.

How to compile
--------------
pdflatex main.tex
pdflatex main.tex

Notes
-----
This package uses the available uploaded figures directly. Some figures are extracted from the original
result PDF and some are cleaner summary plots prepared from the uploaded assets.
